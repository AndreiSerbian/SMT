# 🚀 Инструкция по сборке проекта

Проект использует **Vanilla JavaScript** + **Tailwind CSS** без React и других фреймворков.

## 📦 Установка зависимостей

```bash
npm install
```

## 🛠 Разработка

Запуск локального сервера с автоматической пересборкой CSS:

```bash
npm run dev
```

Проект будет доступен по адресу: http://localhost:8080

## 🏗 Сборка для продакшена

Полная сборка проекта в папку `dist/`:

```bash
npm run build
```

После выполнения команды в папке `dist/` будут:
- ✅ `index.html` - главная страница
- ✅ `styles.css` - минифицированный CSS (Tailwind + кастомные стили)
- ✅ `js/main.js` - бандл всего JavaScript кода
- ✅ `public/` - все изображения, видео и другие ресурсы

## 📁 Структура проекта

```
project/
├── src/
│   └── css/
│       └── input.css           # Входной файл для Tailwind
├── js/
│   ├── app.js                  # Точка входа приложения
│   ├── router.js               # Маршрутизация
│   ├── components/             # Компоненты интерфейса
│   ├── services/               # Бизнес-логика и сервисы
│   ├── utils/                  # Утилиты
│   └── libs/
│       ├── swiper.js          # Локальная обертка для Swiper
│       └── supabaseClient.js  # Локальный клиент Supabase
├── public/
│   ├── css/                    # Кастомные стили
│   ├── images/                 # Изображения
│   └── videos/                 # Видео
├── dist/                       # Собранные файлы (генерируется)
├── build-scripts/
│   └── bundle-js.js           # Скрипт сборки JS
├── tailwind.config.js         # Конфигурация Tailwind
└── index.html                 # Главная HTML страница
```

## 🌐 Деплой на TimeWeb

1. Выполните сборку:
```bash
npm run build
```

2. Загрузите содержимое папки `dist/` в директорию `public_html` на TimeWeb через:
   - FTP-клиент (FileZilla, WinSCP)
   - Файловый менеджер в панели управления

3. Убедитесь, что файл `index.html` находится в корне `public_html/`

## 📋 Доступные команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Запуск dev-сервера с watch-режимом |
| `npm run build` | Полная сборка проекта |
| `npm run preview` | Просмотр собранного проекта |
| `npm run build:css` | Сборка только CSS |
| `npm run build:js` | Сборка только JavaScript |

## 🔧 Используемые технологии

- **Tailwind CSS** - утилитарный CSS-фреймворк (локально)
- **Swiper** - слайдер изображений (npm пакет)
- **Supabase** - backend и база данных (npm пакет)
- **esbuild** - быстрый бандлер JavaScript
- **live-server** - локальный dev-сервер

## 🐛 Решение проблем

### Ошибка при сборке CSS
```bash
npm run build:css
```

### Ошибка при сборке JS
```bash
npm run build:js
```

### Очистка и пересборка
```bash
rm -rf dist node_modules
npm install
npm run build
```

## 📞 Поддержка

При возникновении проблем проверьте:
1. Установлены ли все зависимости (`npm install`)
2. Совместима ли версия Node.js (требуется v16+)
3. Есть ли права на запись в папку `dist/`
