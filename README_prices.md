# Управление ценами товаров

## Как работает система цен

Цены товаров хранятся в таблице `product_prices` в Supabase и загружаются динамически при открытии сайта.

### Структура таблицы цен

```sql
CREATE TABLE product_prices (
  product_id text PRIMARY KEY,        -- ID товара (например: '059', '0591')
  price_rub  numeric NOT NULL,        -- Цена в рублях
  updated_at timestamptz DEFAULT now() -- Время последнего обновления
);
```

## Изменение цен через админ-панель

### Шаг 1: Вход в админ-панель
1. Перейдите на страницу: `ваш-сайт.com/#admin`
2. Введите логин и пароль администратора
3. Нажмите "Войти"

### Шаг 2: Изменение цены товара
1. Найдите нужный товар в списке
2. В поле "Новая цена" введите цену в рублях (только цифры)
3. Нажмите кнопку "💾" рядом с полем ввода
4. Появится уведомление об успешном сохранении

### Шаг 3: Проверка изменений
- Цена автоматически обновится на всех открытых вкладках сайта
- Изменения вступают в силу немедленно

## Поведение товаров без цены

Если у товара нет цены в базе данных:

### На витрине
- Вместо цены отображается **"Цена уточняется"** красным цветом
- Кнопка "Добавить в корзину" заблокирована или скрыта

### В корзине  
- Товары без цены не могут быть добавлены в корзину
- Если цена была удалена после добавления, товар остается с последней известной ценой

## Технические детали

### Безопасность
- Только авторизованные администраторы могут изменять цены
- Действуют политики Row Level Security (RLS)
- Все цены валидируются на сервере

### Производительность  
- Цены кэшируются в браузере
- Используются realtime-обновления через Supabase
- Автоматическая синхронизация между вкладками

### Формат цен
- Только положительные числа
- Поддерживаются дробные значения (например: 299.50)
- Отображение с символом ₽

## Устранение неполадок

### Цена не обновляется
1. Проверьте подключение к интернету
2. Обновите страницу (F5)
3. Проверьте права администратора

### Ошибка сохранения
1. Убедитесь что введена корректная цена
2. Проверьте что вы авторизованы как администратор
3. Попробуйте ввести цену заново

### Товар показывает "Цена уточняется"
1. Зайдите в админ-панель
2. Найдите товар по ID
3. Установите цену через интерфейс админки
