# Система управления ценами

## Описание
Система позволяет управлять ценами товаров через админ-панель с сохранением в базе данных Supabase. Поддерживает realtime обновления и graceful fallback на дефолтные цены.

## Архитектура данных

### Таблица `product_prices`
```sql
CREATE TABLE product_prices (
  product_id text PRIMARY KEY,      -- ID товара из каталога
  price_rub  numeric NOT NULL,      -- Цена в рублях (>= 0)
  updated_at timestamp with time zone DEFAULT now()
);
```

### Файл `data.js` 
Содержит статичный каталог с полем `price_default` для фолбэка:
```javascript
{
  id: "product_1",
  name: "Товар",
  price_default: 1500,  // Резервная цена
  // другие поля...
}
```

## Как работает система

### 1. Загрузка каталога
1. Импортируются товары из `data.js`
2. Загружаются актуальные цены из Supabase
3. Цены объединяются: `finalPrice = dbPrice ?? defaultPrice`
4. При ошибке БД показывается баннер "Цены уточняются"

### 2. Realtime обновления
- Все открытые вкладки автоматически получают обновления цен
- Обновления происходят мгновенно без перезагрузки страницы

### 3. Безопасность
- **Чтение цен**: доступно всем пользователям
- **Изменение цен**: только аутентифицированным админам
- Используется Row Level Security (RLS)

## Инструкция для контент-менеджера

### Вход в админ-панель
1. Перейдите на `/admin` 
2. Введите логин и пароль администратора
3. После входа откроется панель управления

### Изменение цен
1. Найдите нужный товар в списке
2. В поле "Цена" введите новую цену (только цифры)
3. Нажмите кнопку "✓" рядом с полем
4. Появится уведомление "Цена сохранена"
5. Цена автоматически обновится на всех открытых страницах

### Технические работы
- Кнопка "Начать технические работы" временно отключает сайт для посетителей
- В режиме технических работ можно безопасно обновлять цены
- Не забудьте выключить режим после завершения работ

## Технические детали

### Файлы системы
- `js/services/pricesService.js` - основная логика работы с ценами
- `js/data/products.js` - статичный каталог товаров  
- `js/components/adminComponent.js` - админ-панель

### API методы
```javascript
// Загрузка товаров с ценами
const products = await pricesService.loadProductsWithPrices(staticProducts);

// Сохранение цены (только для админов)
const success = await pricesService.savePrice('product_id', 1500);

// Подписка на обновления
pricesService.subscribeToRealtimeUpdates((productId, newPrice) => {
  console.log(`Цена товара ${productId} изменена на ${newPrice}`);
});
```

### Переменные окружения
```
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
```

## Troubleshooting

### Цены не загружаются
1. Проверьте подключение к интернету
2. Убедитесь, что Supabase доступен
3. Проверьте консоль браузера на ошибки
4. При проблемах отображаются дефолтные цены

### Не сохраняются изменения
1. Убедитесь, что вы авторизованы как админ
2. Проверьте корректность введенной цены (только цифры ≥ 0)
3. Проверьте подключение к базе данных

### Не работают realtime обновления  
1. Перезагрузите страницу
2. Проверьте статус Supabase
3. Убедитесь, что не заблокированы WebSocket соединения

## Поддержка
При проблемах обратитесь к разработчику с указанием:
- Времени возникновения проблемы
- Текста ошибки из консоли браузера
- Действий, которые к ней привели
