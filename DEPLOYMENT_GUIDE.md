# 🚀 Руководство по деплою на TimeWeb

## Вариант 1: Стандартный деплой (рекомендуется)

### Шаг 1: Сборка проекта
```bash
npm run build
```

### Шаг 2: Структура файлов для загрузки
После сборки в папке `dist/` будут:
```
dist/
├── index.html          # Главная страница
├── styles.css          # Все стили (минифицированные)
├── js/
│   └── main.js        # Весь JavaScript (бандл)
└── public/
    ├── images/        # Все изображения
    ├── videos/        # Все видео
    └── css/           # Дополнительные стили
```

### Шаг 3: Загрузка на TimeWeb

#### Через FTP:
1. Подключитесь к TimeWeb по FTP (FileZilla, WinSCP)
2. Откройте папку `public_html` на сервере
3. Загрузите **ВСЕ содержимое** папки `dist/` в `public_html/`

Должна получиться структура:
```
public_html/
├── index.html
├── styles.css
├── js/
│   └── main.js
└── public/
    └── ...
```

#### Через файловый менеджер TimeWeb:
1. Зайдите в панель управления TimeWeb
2. Откройте "Файловый менеджер"
3. Перейдите в `public_html`
4. Удалите старые файлы (если есть)
5. Загрузите содержимое папки `dist/`

### Шаг 4: Проверка
Откройте ваш домен в браузере. Сайт должен работать без ошибок.

## Вариант 2: Standalone файл (экспериментально)

Создание единого HTML файла со встроенными CSS и JS:

```bash
npm run build
node build-scripts/create-standalone.js
```

Загрузите `dist/standalone.html` + папку `dist/public/` на сервер.

⚠️ **Внимание**: Этот вариант увеличит размер HTML файла.

## 🔧 Настройка .htaccess для SPA

Если используется роутинг через хеш (#), создайте `.htaccess` в `public_html/`:

```apache
# Включить mod_rewrite
RewriteEngine On

# Редирект всех запросов на index.html
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^.*$ /index.html [L]

# Кеширование статических файлов
<FilesMatch "\.(jpg|jpeg|png|gif|webp|svg|ico|css|js|woff|woff2)$">
  Header set Cache-Control "max-age=31536000, public"
</FilesMatch>

# Сжатие
<IfModule mod_deflate.c>
  AddOutputFilterByType DEFLATE text/html text/css application/javascript
</IfModule>
```

## 🐛 Решение проблем

### Проблема: Белый экран после загрузки
**Решение**: Проверьте пути к файлам. Они должны быть относительными (`./styles.css`, `./js/main.js`)

### Проблема: CSS не загружается
**Решение**: 
1. Проверьте, что `styles.css` лежит рядом с `index.html`
2. Откройте Developer Tools → Network и проверьте ответ сервера

### Проблема: JavaScript не работает
**Решение**: 
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что `type="module"` указан в теге `<script>`

### Проблема: Изображения не отображаются
**Решение**: 
1. Проверьте пути к изображениям в коде
2. Убедитесь, что папка `public/` загружена полностью

## 🔄 Обновление сайта

Для обновления сайта:
1. Внесите изменения в код
2. Выполните `npm run build`
3. Замените файлы на сервере новыми из `dist/`

## 🌐 DNS и домен

Если сайт не открывается по домену:
1. Проверьте DNS записи в панели TimeWeb
2. Подождите 24-48 часов для распространения DNS
3. Очистите кеш браузера
