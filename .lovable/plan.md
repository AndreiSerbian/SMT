# Mockup POC — статус и следующий шаг: доработка closed_45.svg

## Что показал аудит (кратко)

Технически POC работает полностью: модалка, зоны, перекраска только `zone-side`, палитра каталога, цена ×1.10, mobile 390/375/360 без overflow, focus trap, Escape, backdrop, возврат фокуса — всё PASS, runtime-ошибок нет.

Единственная незакрытая часть — визуальное качество `public/mockups/magnet_box/default/closed_45.svg`. Сейчас это простая аксонометрическая коробка из трёх плоских полигонов: нет толщины картона, нет свеса крышки, нет скруглений и мягких теней в стыках. Боковушка читается как плоский цветной прямоугольник, а не как часть коробки на магнитах.

## Следующий шаг: A — Refine closed_45.svg

Только геометрия и освещение внутри одного файла SVG. Данные, сервис, модалка, CSS, mapping, цена и палитра не меняются.

### Что улучшить в SVG

1. Толщина материала: у крышки добавить видимую кромку (2–4 px в координатах viewBox) по переднему и боковому ребру — так коробка перестаёт выглядеть «бумажной».
2. Свес крышки: крышка магнитной коробки чуть шире корпуса — небольшой outset по периметру верхней части.
3. Разделение крышка/корпус: заменить текущую одиночную линию на пару граней с собственным затенением, чтобы линия стыка читалась объёмно.
4. Скругление рёбер: мягкие фаски на вертикальном переднем ребре через узкий градиентный полигон.
5. Освещение: усилить контраст между top / front / side, добавить контактную тень у основания (сейчас только общая эллиптическая тень).
6. Проверить, что все новые декоративные слои остаются полупрозрачными поверх зон — чтобы перекраска `--zone-side` и `--zone-outer-*` сохраняла объём.

### Зоны и контракт (не меняются)

- `#zone-outer-top`, `#zone-outer-front` — `var(--zone-outer-top/front)`
- `#zone-side` — `var(--zone-side)`, единственная перекрашиваемая зона POC
- Кромки крышки наследуют цвет соответствующей зоны, а не задаются жёстко

### Проверка после доработки

- Скриншот SVG при базовом цвете + при контрастном втором цвете
- `--zone-side` меняет только боковушку, объём и тени сохраняются
- Один запрос SVG, отсутствие console/page errors
- Mobile 390/375/360: `scrollWidth === clientWidth`

### Вне scope этого шага

`open_45`, `bow_box`, `bag_box`, корзина, заказ, Supabase, Storage, customizer.
