# Переработка геометрии magnet_box / closed_45.svg

Изменяется ровно один файл: `public/mockups/magnet_box/default/closed_45.svg`. Больше ничего.

Примечание: фотографии реальной коробки к сообщению не приложены. Геометрия строится по текстовому описанию конструкции из PRD (складная магнитная коробка 21×15×8, скрытые магниты). Если фото будут приложены, геометрию скорректирую по ним.

## P0 — конструкция

- Убрать схему «корпус + отдельная съёмная крышка». Коробка строится как единая складная оболочка.
- Сторона закрывания (`#zone-outer-front`) — это закрывающая панель, идущая от верхней панели вниз до основания. Под ней НЕ рисуется вторая полноценная вертикальная стенка корпуса.
- Переход верх → закрывающая панель показывается как складка: тонкая кромка картона (~2–3 units) плюс мягкая линия сгиба, без массивного свеса.
- Свес минимальный (0–2 units) или отсутствует; вместо него — толщина материала по верхнему ребру.
- Никаких замков, петель, ручек, банта, кружков-магнитов, прорезей.

## P0 — пропорции и ракурс

- Пропорции ~21 (ширина) × 15 (глубина) × 8 (высота): высота фронтальной плоскости заметно снижается относительно текущей версии.
- Камера поднимается: верхняя панель занимает существенно бо́льшую площадь кадра, чем сейчас; фронт перестаёт доминировать.
- `#zone-side` — полноценная видимая боковая грань с корректной перспективой, достаточно крупная, чтобы второй цвет читался как дизайнерское решение.
- Все три плоскости сходятся в общих рёбрах (общие вершины, без зазоров и наложений).

## P1 — кромки и складки

Каждая поверхность = базовая зона + декоративные полупрозрачные слои:

```text
zone-side
  + side-edge-shadow   (стык с front)
  + side-top-shadow    (под верхним ребром)
  + side-highlight     (кромка/фаска)
```

- Тонкое вертикальное ребро front↔side, тонкая линия сгиба верх↔front, узкая фаска по нижнему краю.
- Все линии тонкие и полупрозрачные; никакого CAD-вида.

## P1 — освещение

- top светлее, front среднее, side темнее — исключительно через полупрозрачные overlay/градиенты поверх зон, без жёстких HEX.
- Контактные тени: под верхней кромкой, у стыка front↔side, у нижней границы.
- Ground shadow остаётся, но ослабляется — объём должен читаться по самой коробке.

## P2 — фактура

Очень лёгкая неравномерность освещения, только если не мешает перекраске. Делается последней и может быть опущена.

## Контракт зон (не меняется)

- `#zone-outer-top` → `var(--zone-outer-top)`
- `#zone-outer-front` → `var(--zone-outer-front)` (теперь физически = закрывающая панель)
- `#zone-side` → `var(--zone-side)` — единственная зона второго цвета
- Кромки наследуют цвет своей зоны; тени/блики — прозрачные overlay без собственного цвета.

## Проверка

- Runtime на товаре `full-cover-small`: смена `--zone-side` без повторной загрузки SVG, один запрос SVG, отсутствие console/page errors.
- Mobile 390 / 375 / 360 — без overflow-регрессий.
- Три скриншота: (A) white/white, (B) gold/red, (C) black + red или gold.
