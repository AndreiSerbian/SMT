# Переработка геометрии magnet_box / closed_45.svg

Изменяется ровно один файл: `public/mockups/magnet_box/default/closed_45.svg`. Больше ничего.

Геометрический эталон: приложенное фото оранжевой магнитной коробки 21×15×8 (primary reference). Только по нему определяются камера, перспектива, площадь top, высота, ширина боковушки. Другие фото/цвета не смешиваются в геометрию.

## P0 — конструкция

- Единая складная оболочка вместо «корпус + съёмная крышка».
- Front wall существует физически; closing panel опускается поверх неё и закрывает снаружи. Двухслойность читается через геометрию, толщину материала, боковую кромку панели и контактную тень в стыке. Нижний свес панели не обязателен — показывается только в той степени, в какой реально читается на primary reference.
- Верхняя панель — часть той же оболочки, с тонкой толщиной картона по переднему и боковому ребру (без массивного lip). Переход top → closing panel строится по reference через геометрию, кромку, толщину, сгиб и/или тень; отдельная декоративная линия сгиба добавляется только если подтверждается фотографией.

- Магниты скрыты и не изображаются. Никаких замков, петель, ручек, банта, прорезей, кружков.

## P0 — пропорции и ракурс

- Пропорции ~21 × 15 × 8: заметно снизить визуальную высоту вертикальных плоскостей относительно текущей версии.
- Камера поднимается: top занимает существенно бо́льшую площадь, вертикальные грани не доминируют.
- `#zone-side` — реальная боковая грань с перспективой по reference; её размер не раздувается искусственно ради второго цвета.
- Общие вершины у всех поверхностей: без зазоров, случайных пересечений и наложений.

## P1 — кромки и складки

Каждая поверхность = базовая зона + прозрачные декоративные слои:

```text
zone-side
  + side-edge-shadow   (стык с closing panel)
  + side-top-shadow    (под верхним ребром)
  + side-highlight     (кромка/фаска)
```

- Тонкое вертикальное ребро front↔side, узкий нижний кант, деликатная фаска на кромке панели; линия сгиба top↔closing panel — только при подтверждении по reference.
- Все линии тонкие и полупрозрачные; никакого CAD-вида.

## P1 — освещение

- top светлее, front среднее, side темнее — только полупрозрачными overlay/градиентами поверх выбранного цвета, без жёстких HEX.
- Контактные тени: под кромкой top, между closing panel и front wall, у перехода front↔side, у нижнего края.
- Ground shadow остаётся, но ослабляется: объём читается по самой коробке.

## P2 — фактура

Очень лёгкая неравномерность, только после успешных P0/P1 и только если не мешает перекраске.

## Контракт зон (не меняется)

- `#zone-outer-top` → `var(--zone-outer-top)` — основной цвет
- `#zone-outer-front` → `var(--zone-outer-front)` — основной цвет, физически = видимая closing panel
- `#zone-side` → `var(--zone-side)` — единственная зона второго цвета
- Кромки наследуют цвет своей зоны; тени/блики — прозрачные слои без собственного цвета.

## Проверка

- Runtime на `full-cover-small`: один запрос SVG на открытие, смена `--zone-side` без перезагрузки, `zone-outer-top` / `zone-outer-front` не меняются, 0 console/page errors, открытие/закрытие модалки.
- Mobile 390 / 375 / 360 — без overflow.
- Три скриншота из работающего POC: white/white, gold/red, black/red.
- При обнаружении регрессии — сообщить, а не расширять scope.
